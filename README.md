  # 🎵 Spotify Web Player Clone

  **A pixel-perfect, static clone of the Spotify Web Player UI built entirely with HTML and CSS.**

## ✨ Features

- **Responsive Layout:** Adapts seamlessly to different screen sizes.
- **Sidebar Navigation:** Classic Spotify sidebar with links and library.
- **Music Player Controls:** Fixed bottom playback bar (UI only).
- **Card-Based Content Display:** Beautifully structured grid layouts for albums and playlists.
- **Hover Effects & Transitions:** Smooth micro-interactions for a premium feel.



## 📂 File Structure

```text
├── index.html        # Main entry point containing the structure
├── spotify.css       # Stylesheet with custom properties and layout
└── icons/            # Image and icon assets
```
