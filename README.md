# Spotify Web Player Clone

This is a static clone of the Spotify Web Player UI built with HTML and CSS.

## Features
- Responsive layout
- Sidebar navigation
- Music player controls
- Card-based content display

## Deployment
This project is ready to be deployed on Netlify or any static hosting service.

### Deploying to Netlify
1. Push this repository to GitHub (or your preferred Git provider).
2. Go to [Netlify](https://www.netlify.com/) and sign in.
3. Click "Add new site" > "Import an existing project".
4. Connect your repository and follow the prompts.
5. Netlify will automatically detect `index.html` as the entry point and deploy your site.

## File Structure
- `index.html` - Main entry point
- `spotify.css` - Stylesheet
- `icons/` - Image and icon assets
